### 📡 RFwatch — *open-source RF monitoring tool*
A desktop application for detecting, analyzing, and visualizing RF signals in real time using HackRF One. Built on GNU Radio with a clean four-layer architecture: UI → EngineController → Engine pipeline → IQ hardware source. Operates strictly at the physical layer — no protocol decoding, no modulation guessing, no black-box classification. Everything is deterministic and traceable back to observable RF behavior. Dual modes: Inspector (single-band continuous monitoring) and Scanner (wideband sweep). Includes event-centric signal tracking, SNR-based detection, and TX test signal capabilities.

→ [github.com/Pranav-d33/RFwatch](https://github.com/Pranav-d33/RFwatch)
